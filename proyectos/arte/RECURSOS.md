# Recursos gráficos del menú

Los iconos y dibujos de esta entrega se han creado desde cero con código, geometría y caracteres. Las capturas aportadas se han usado como referencia de estilos; los trazados son nuevos.

| Recurso | Contenido | Procedencia |
| --- | --- | --- |
| `iconos.svg` | Casa, búsqueda, paleta, enlace, cierre, libro, conversión, ruleta y código | Dibujos originales sobre cuadrícula de 24 unidades. |
| `dibujos.svg#robot` y `#paisaje` | Robot y pequeño paisaje de píxeles | Figuras originales. |
| `dibujos.svg#engranaje` | Engranaje geométrico | Dientes calculados alternando radios de un círculo. |
| `dibujos.svg#isometrico` | Mesa, portátil y bloques azules | Polígonos originales. |
| `dibujos.svg#lineas` | Líneas con desplazamiento ondulado | Curvas generadas con funciones matemáticas. |
| `fotogramasAscii` en `../temas.js` | Cubo hecho con caracteres | Fotogramas originales escritos para este menú. |
